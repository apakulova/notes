# Личный учебный архив

Главная страница — каталог курсов. Каждый курс хранится в отдельном вложенном разделе.

- `index.html` — каталог всех курсов.
- `first-time-management/` — программа и материалы курса по менеджменту.
- `figma-ux-editors/` — сохранённый курс по Figma для UX-редакторов.

Опубликованная версия работает через GitHub Pages.
